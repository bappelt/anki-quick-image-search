# Changelog

All notable changes to Quick Image Search for Anki are recorded here. The
format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Each release's section becomes its GitHub release notes. Versions 1.0.0 and
1.1.0 were published on AnkiWeb before releases were tagged, so they have no
tag or GitHub release.

## [Unreleased]

## [1.1.1] - 2026-10-24

### Fixed

- No more "model is deprecated" warning in recent Anki versions when
  searching.

## [1.1.0] - 2026-08-29

### Added

- A configurable keyboard shortcut for the Search Images button, default
  `Ctrl+Shift+1` (`Shift+Cmd+1` on macOS). Change or clear it in the config
  dialog.

## [1.0.0] - 2026-04-18

- Initial release.
