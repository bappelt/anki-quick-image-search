Adds a Search Images button to the editor toolbar in the Browse window. Clicking it opens an image search for the text in a configurable note field — making it easy to find images for your flashcards without leaving Anki.

Features

  • Toolbar button in the Browse window editor
  • Searches the configured note field (falls back to the first field if not found)
  • Supports 12 Google country domains plus a custom domain option
  • Configurable keyboard shortcut (default Ctrl+Shift+1, Shift+Cmd+1 on macOS)
  • Simple settings dialog

Configuration

Go to Tools → Add-ons → Quick Image Search for Anki → Config

Field name — which note field to search (default: Front)

Google domain — which Google domain to use for language appropriate results (default: google.com.)

Shortcut — keyboard shortcut for the Search Images button (default: Ctrl+Shift+1). Clear it to disable the shortcut.
